# Ricetta Screens

## 画面一覧

MVPで扱う画面は以下です。

| ID | 画面名 | 目的 |
|---|---|---|
| 01_Login | ログイン | アプリに入る |
| 02_Dashboard | ダッシュボード | 今日の現場を確認する |
| 03_Prep_Today | 今日の仕込み | 仕込み予定を確認・更新する |
| 04_Prep_Action_Modal | 仕込み操作モーダル | 仕込みカードの操作を選ぶ |
| 05_Recipe_List | レシピ一覧 | レシピを探す |
| 06_Recipe_Detail | レシピ詳細 | 材料・作り方・原価を確認する |
| 07_Recipe_Edit | レシピ作成/編集 | レシピを登録・編集する |
| 08_Ingredient_List | 材料一覧 | 材料マスターを探す |
| 09_Ingredient_Detail | 材料詳細 | 仕入・換算・単価を確認する |
| 10_Ingredient_Edit | 材料作成/編集 | 材料を登録・編集する |
| 11_Settings | 設定 | カテゴリ・単位・店舗情報を管理する |

補助画面：

- Category Settings
- Unit Settings

## 共通UI方針

### ナビゲーション

スマホ：

- 下部ナビ
- ホーム / 仕込み / レシピ / 材料

タブレット横・PC：

- 左固定サイドバー
- 幅は約120px
- テキストのみ
- カード型
- 常時表示

サイドバー項目：

- ホーム
- 仕込み
- レシピ
- 材料
- 設定

### 戻るボタン

詳細・編集系の画面には、左上に「← 戻る」を表示します。

目的：

- 一覧のスクロール位置や検索状態を保ったまま戻る
- 直前に見ていた画面へ戻る
- サイドバー遷移と役割を分ける

戻る導線の例：

- Recipe List → Recipe Detail → 戻る → Recipe List
- Prep Today → Recipe Detail → 戻る → Prep Today
- Recipe Detail → Recipe Edit → 戻る → Recipe Detail

## 01_Login

### 目的

OwnerがRicettaにログインする画面です。

### 主な表示項目

- Ricetta
- 小さな飲食店のための、レシピ台帳。
- メールアドレス
- パスワード
- ログインボタン
- エラーメッセージ

### 主な操作

- メールアドレス入力
- パスワード入力
- ログイン

### 備考

MVPでは新規登録やパスワードリセットは後回しでも可とします。

## 02_Dashboard

### 目的

ログイン後に最初に開く、業務開始画面です。

単なるホームではなく、「今日の現場」を確認する画面です。

### 主な表示項目

- 今日の現場
- 日付
- 今日の仕込みサマリー
- 次にやること
- 期限注意
- よく使うレシピ
- クイックアクション
- ミニサマリー

### 表示例

#### 今日の仕込み

- 未着手 3件
- 作業中 1件
- 完了 2件

#### 次にやること

- トマトソース 3バッチ
- プリン 20個
- 鶏ハム 2kg

#### 期限注意

- プリン 今日まで
- トマトソース 明日まで

#### よく使うレシピ

- トマトソース
- ドレッシング
- プリン

### 主な操作

- 今日の仕込みを見る
- 次にやることからレシピ詳細へ遷移
- レシピを探す
- 材料を確認する

### Figmaワイヤー向けメモ

タブレット横では2カラム構成にします。

左カラム：

- 今日の仕込みサマリー
- 次にやること
- 今日の仕込みを見るボタン

右カラム：

- クイックアクション
- よく使うレシピ
- 期限注意
- ミニサマリー

Dashboardでは「今日何をするか」が最初に分かることを優先します。

## 03_Prep_Today

### 目的

ホワイトボードに書いていた「今日の仕込み」を置き換える画面です。

仕込みタスクをステータス別に表示します。

### 主な表示項目

- 今日の仕込み
- 日付
- ステータス別summary
- 未着手
- 作業中
- 完了
- 仕込みカード

### 仕込みカードの表示項目

- レシピ名
- 予定数量
- 単位
- メモ
- 完了時刻

例：

- トマトソース 3バッチ
- プリン 20個
- カレーソース 2バッチ

### 主な操作

- 仕込みカードをタップ
- 作業中にする
- 完了にする
- 未着手に戻す

MVP初期frontendでは、カード内のstatus変更ボタンで更新します。Prep Action Modal、レシピを見る導線、仕込みタスク追加UIは後続フェーズで実装します。

### UI方針

- ドラッグ操作は使わない
- タップ操作を基本にする
- カードは大きめ
- 厨房タブレットで押しやすくする

### Figmaワイヤー向けメモ

スマホ：

- ステータスごとの縦リスト

タブレット横：

- 3カラム構成
- 未着手 / 作業中 / 完了

## 05_Recipe_List

### 目的

店舗内のレシピを探す画面です。

### 主な表示項目

- レシピ一覧
- 検索欄
- カテゴリフィルター
- レシピカード
- 新規作成ボタン（後続フェーズ）

### レシピカードの表示項目

- 写真
- レシピ名
- カテゴリ
- 基準量

例：

- トマトソース / 仕込み / 基準：1バッチ
- プリン / デザート / 基準：20個
- ドレッシング / 仕込み / 基準：1L

### 主な操作

- 検索
- カテゴリ絞り込み
- レシピ詳細へ遷移
- 新規レシピ作成へ遷移（後続フェーズ）

MVP初期frontendでは、検索と一覧・詳細閲覧を先に実装します。作成・編集フォームは後続フェーズで実装します。

## 06_Recipe_Detail

### 目的

レシピを現場で確認する中心画面です。

材料・分量・作り方・注意点を見やすく表示します。

### 主な表示項目

- 戻るボタン
- レシピ名
- カテゴリ
- 完成写真
- 説明
- 基準量
- 仕込み量
- 材料
- 作り方
- 注意点
- アレルゲン
- 原価情報
- 編集ボタン（後続フェーズ）

### 材料セクション

材料セクションには、原価情報を表示しません。

表示するもの：

- 材料名
- 使用量
- 単位

例：

- ホールトマト 6缶
- 玉ねぎ 900g
- にんにく 30g
- オリーブオイル 180ml
- 塩 36g

### 原価情報セクション

原価情報は専用カードに集約します。

表示例：

- 材料原価：480円
- 販売価格：1,200円
- 原価率：40%
- 粗利：720円

販売価格が未設定の場合：

- 材料原価：480円
- 販売価格：未設定
- 原価率：-

### 主な操作

- 戻る
- 仕込み量変更
- 編集へ遷移（後続フェーズ）
- 原価情報確認

MVP初期frontendでは閲覧画面を優先します。材料欄には原価情報を混ぜず、原価は専用カードに集約します。

### Figmaワイヤー向けメモ

優先表示順：

1. レシピ名
2. 仕込み量
3. 材料
4. 作り方
5. 注意点
6. 原価情報

タブレット横では、なるべく1画面で材料と作り方が見えるようにします。

### 主な表示項目

- 材料一覧
- 検索欄
- 材料カード
- 原価計算モード
- 単価表示
- 仕入先

### 主な操作

- 検索
- 材料詳細へ遷移

## 09_Ingredient_Detail

### 目的

材料の仕入情報、使用単位、換算情報、単価表示を確認する画面です。

### 主な表示項目

- 戻るボタン
- 材料名
- 仕入先
- メモ
- 原価計算モード
- 仕入数量
- 仕入単位
- 仕入価格
- 使用単位
- 換算情報
- 単価表示

### 原価計算モード

```text
none       -> 原価計算しない
same_unit  -> 仕入単位のまま計算
conversion -> 使用単位に換算して計算
```

Ingredient Detailは材料マスター管理寄りの画面なので、原価・換算情報を表示してよいです。一方で、Recipe Detailの材料欄にはこれらの情報を混ぜません。

### 主な操作

- 戻る
- 原価情報確認
- 編集へ遷移

## 10_Ingredient_Edit

### 目的

材料を新規作成・編集する画面です。

### 主な表示項目

- 戻るボタン
- 材料名
- 仕入先
- メモ
- 原価計算モード
- 仕入数量
- 仕入単位
- 仕入価格
- 使用単位
- 換算元数量
- 換算元単位
- 換算先数量
- 換算先単位
- 保存ボタン

### cost_modeごとの表示

`none`:

- 材料名
- 仕入先
- メモ
- 原価計算モード

`same_unit`:

- 仕入数量
- 仕入単位
- 仕入価格
- 使用単位

MVPでは、仕入単位を選ぶと使用単位も同じ値に自動設定します。

`conversion`:

- 仕入数量
- 仕入単位
- 仕入価格
- 使用単位
- 換算元数量
- 換算先数量

MVPでは、換算元単位は仕入単位、換算先単位は使用単位に自動設定します。

### 主な操作

- 保存
- キャンセル
- 戻る

保存失敗時は入力内容を消さず、frontend validationとbackend validation errorを表示します。


### レシピ閲覧導線


```text

```

## 画面設計の重要方針

- Dashboardは「今日の現場」を確認する画面
- Prep Todayはホワイトボード代替
- Recipe Detailは現場で見る画面
- Recipe Editは管理・登録画面
- Ingredient Detailは材料マスター管理画面
- 材料欄に原価情報を混ぜない
- 原価情報は専用カードに集約する
- 戻るボタンで直前の文脈に戻れるようにする
- タブレット横向きでは120px固定サイドバーを使う
