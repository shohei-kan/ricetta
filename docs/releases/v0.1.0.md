# Ricetta v0.1.0

## 概要

Ricettaの初回公開デモリリースです。

小規模飲食店向けのレシピ管理、材料管理、原価計算、仕込み管理を確認できる公開デモ環境をリリースしました。

## 主な機能

- レシピ管理
- 材料管理
- 原価計算
- 今日の仕込み
- owner / staff権限制御
- レスポンシブ対応

## 公開環境

- AWS EC2
- Docker Compose
- PostgreSQL
- Gunicorn
- Caddy HTTPS
