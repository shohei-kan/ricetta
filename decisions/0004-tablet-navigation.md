# 0004 Tablet Navigation

## Date

2026-05-04

## Status

Accepted

## Context

Ricettaは、スマホ・タブレット・PCで使う想定です。

特にタブレットは、厨房や仕込み場に横置きして使うシーンを重視します。

初期検討では、タブレット横向きで下部ナビ、開閉式サイドバー、固定サイドバーを検討しました。

実際の現場利用を考えると、開閉式サイドバーは以下の課題があります。

- 開く/閉じる操作が増える
- 現在地が分かりにくくなる
- UIが変化して落ち着かない
- 厨房タブレットでは一手間になる

## Decision

デバイス別にナビゲーションを分けます。

### スマホ

下部ナビを使います。

項目：

```text
ホーム
仕込み
レシピ
材料
```

### タブレット横・PC

左固定サイドバーを使います。

仕様：

- 幅：約120px
- 常時表示
- 開閉しない
- テキストのみ
- カード型
- アイコンなし

項目：

```text
ホーム
仕込み
レシピ
材料
設定
```

## Sidebar Design

サイドバーは、見た目より分かりやすさを優先します。

方針：

- アイコンに頼らない
- テキストだけで分かる
- カード型で押しやすい
- 選択中状態を明確にする
- 店舗名は下部に控えめに表示する

表示例：

```text
Ricetta

[ ホーム ]
[ 仕込み ]
[ レシピ ]
[ 材料 ]
[ 設定 ]

〇〇食堂
owner
```

## Reasons

### 1. 厨房タブレットで迷わないため

厨房では、すぐに画面移動できることが重要です。

常に同じ場所に同じメニューがある方が使いやすいです。

### 2. 横画面を有効に使うため

タブレット横向きでは、120px程度のサイドバーを置いてもメイン領域を十分に確保できます。

レシピ詳細では、材料と作り方を同時に見せやすくなります。

### 3. アイコンより文字の方が分かりやすいため

現場では、アイコンの意味を考えるより、文字で読める方が早いです。

そのため、サイドバーはテキストのみとします。

### 4. 開閉式より安定するため

開閉式は便利に見えますが、現場では一手増えます。

Ricettaでは、複雑なUIより常時表示の安定感を優先します。

## Consequences

### Positive

- 現在地が分かりやすい
- 主要メニューにすぐアクセスできる
- タブレット横向きで業務アプリらしくなる
- UIが安定する

### Negative

- メイン領域が120px分狭くなる
- スマホとタブレットでナビ実装が分かれる
- サイドバーのレスポンシブ設計が必要

## UI Notes

- サイドバー文字サイズは16〜18px程度
- カード高さは48〜56px程度
- 選択中カードは淡いアクセント背景
- サイドバーは目立ちすぎない
- 仕込みはRicettaの主導線なので2番目に置く
