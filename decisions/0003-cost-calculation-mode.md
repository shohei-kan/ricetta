# 0003 Ingredient Cost Calculation Mode

## Date

2026-05-04

## Status

Accepted

## Context

Ricettaでは、レシピごとの材料原価や原価率を確認できるようにします。

ただし、小規模飲食店では、すべての材料を厳密にg/ml換算して管理するとは限りません。

例：

- 卵は「個」で管理したい
- ホールトマトは「缶」で仕入れて「g」で使いたい
- 塩少々や水は原価計算から外したい
- 原価率をそこまで気にしない店舗もある

最初からすべての材料に厳密な換算登録を強制すると、入力負荷が高くなり、MVP利用のハードルが上がります。

## Decision

材料ごとに、原価計算モードを選べるようにします。

モードは以下の3種類です。

```text
none
same_unit
conversion
```

表示名：

```text
原価計算しない
仕入単位のまま計算
使用単位に換算して計算
```

## Modes

### none

原価計算しない。

対象例：

- 水
- 塩少々
- 飾り
- 適量の胡椒

このモードの材料は、レシピ原価に含めません。

### same_unit

仕入単位のまま計算する。

例：

```text
卵 1個 = 30円
レシピで3個使用
原価 = 90円
```

### conversion

使用単位に換算して計算する。

例：

```text
ホールトマト 1缶 = 180円
1缶 = 400g
レシピで200g使用
原価 = 90円
```

## MVP Scope

MVPで対応すること：

- 原価計算ON/OFF
- 仕入単位のまま計算
- 1段階の簡易換算
- kg ⇔ g
- L ⇔ ml
- 缶 → g
- 袋 → g
- 本 → ml
- 材料ごとの換算情報登録

MVPで対応しないこと：

- 歩留まり
- 廃棄率
- 加熱後重量
- 複数段階換算
- 在庫連動
- 仕入価格履歴
- POS連携

## UI Decision

材料登録画面では、原価計算モードを選択できるようにします。

表示例：

```text
計算しない
水・飾りなど

そのまま計算
1個30円 → 3個使用

換算して計算
1缶180円 / 1缶400g
```

Recipe Detailでは、材料欄に原価情報を表示しません。

材料欄は「作るための情報」に集中します。

原価は「原価情報」カードに集約します。

## Reasons

### 1. 入力の重さを下げるため

原価を細かく管理したい材料だけ換算登録できるようにします。

すべての材料に厳密入力を強制しません。

### 2. 小規模店の現場感に合うため

飲食店では、材料によって単位管理がバラバラです。

「缶」「個」「袋」「g」「ml」などが混在するため、柔軟な設計が必要です。

### 3. MVPを大きくしすぎないため

歩留まりや加熱後重量まで扱うと、業務システムとして重くなります。

MVPでは1段階換算までに留めます。

## Consequences

### Positive

- 原価管理したい店舗にも対応できる
- 原価を気にしない店舗でも使える
- 入力負荷を調整できる
- MVPとして実装しやすい

### Negative

- 厳密な食品製造原価管理には不足する
- 歩留まりや廃棄率は計算できない
- 材料ごとに換算設定が必要なケースがある
